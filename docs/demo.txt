 AllRAM — как это работает
──────────────────────────────────────────────────────────────────────────
Как это работает
────────────────
1. Windows не даёт «дописать» физическую ОЗУ в реестр: объём памяти определяет
   ядро при загрузке, и значение в реестре — только снимок для отображения.
2. Зато Windows официально умеет расширять память файлом подкачки на диске.
   Сумма «ОЗУ + файл подкачки» называется commit limit — это тот объём,
   который программы видят как доступную память.
3. AllRAM создаёт такой файл на выбранном SSD и прописывает его в реестр
   (HKLM\SYSTEM\CurrentControlSet\Control\Session Manager\Memory Management,
   значения PagingFiles и AutomaticManagedPagefile). Настройка переживает
   перезагрузку, работает для всех программ и для нейросетей.
4. Скорость: ОЗУ — десятки ГБ/с, SSD — сотни МБ/с…несколько ГБ/с.
   Поэтому расширенная память работает, но медленно. AllRAM умеет это измерить
   командой `allram bench`.
5. Второй режим — RAM-диск ImDisk: часть настоящей ОЗУ превращается в диск.
   Он быстрый, но данные в нём не сохраняются после выключения.
