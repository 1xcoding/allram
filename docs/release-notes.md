## AllRAM 1.0.0 — SSD как дополнительная память Windows

Терминальная утилита без графического интерфейса: превращает свободное место
на SSD в дополнительную память, которой пользуются все программы — браузеры,
игры, виртуальные машины и нейросети.

### Что в этой версии

- `allram setup` / `allram auto` — переносит файл подкачки на выбранный диск,
  задаёт размер и прописывает настройки в реестр
  (`HKLM\SYSTEM\CurrentControlSet\Control\Session Manager\Memory Management`).
- `allram ramdisk` — RAM-диск в настоящей ОЗУ через свободный драйвер ImDisk
  (с автоматической загрузкой и установкой).
- `allram status` — ОЗУ, занятость, файлы подкачки, RAM-диски, состояние реестра.
- `allram bench` — сравнение скорости ОЗУ и SSD: наглядно показывает,
  насколько «расширенная» память медленнее настоящей.
- `allram models` — прикидкa, какие локальные нейросети поместятся в память.
- `allram watch` — наблюдение в реальном времени и предупреждение о нехватке памяти.
- `allram revert` — возврат прежних настроек подкачки из резервной копии.
- `allram explain`, `allram recommend`, `allram history`, `allram settings`.
- Интерактивное меню при запуске без аргументов.
- Один файл `allram.exe`, без Python и без зависимостей.

### Установка

1. Скачайте `allram.exe` (или `allram-win64.zip`) ниже.
2. Запустите правой кнопкой → «Запуск от имени администратора».
3. `allram auto --apply`, затем перезагрузите Windows.

Контроль целостности: `certutil -hashfile allram.exe SHA256`
и сравните с `SHA256SUMS.txt`.

### Честно о главном

Оперативную память нельзя «дописать в реестр»: её объём определяет ядро при
загрузке. AllRAM делает то, что действительно работает: включает файл подкачки
на SSD и настраивает его так, чтобы Windows отдавала программам больший общий
объём памяти. Этот объём медленнее настоящей ОЗУ, зато он настоящий: в нём
помещаются нейросети, которые иначе не запустились бы.

### Требования

Windows 10/11 (x64), права администратора, перезагрузка после изменения подкачки.
