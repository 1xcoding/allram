# Иконка AllRAM

`assets/allram.ico` — многоразмерная иконка Windows (16, 24, 32, 48, 64, 128, 256 px).
Она встраивается в `allram.exe` при сборке (`scripts/build.py`).

Иконка нарисована кодом (`scripts/make_icon.py`) и не требует внешних файлов:
тёмно-синий квадрат со скруглением, стилизованная планка памяти и молния.
Пересоздать:

```bash
python scripts/make_icon.py
```

Формат ICO собирается вручную (заголовки ICO + PNG-кадры), потому что AllRAM
не использует сторонние библиотеки. Если иконка не нужна — удалите файл,
сборка пройдёт без неё.
